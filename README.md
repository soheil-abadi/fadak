# همراه | جست‌وجوی هتل با تجربه فارسی

«همراه» یک برنامه قابل اجرای Next.js برای تسک ارزیابی فرانت‌اند است: جست‌وجوی هتل با تقویم شمسی، فیلتر و مرتب‌سازی قابل بازیابی از URL، جزئیات اقامتگاه و پیش‌نمایش رزرو. رابط کاملاً فارسی و راست‌به‌چپ است و برای موبایل و دسکتاپ طراحی شده است.

داده‌ها Mock و تصاویر تولیدشده با هوش مصنوعی هستند. این برنامه به بازار زنده متصل نیست و رزرو یا پرداخت واقعی انجام نمی‌دهد. مبنای نیازمندی‌ها سند «تسک ارزیابی توسعه دهنده فرانت اند.docx» است؛ نگاشت آن در [نیازمندی‌ها](docs/requirements.md) آمده است.

## اجرای محلی

پیش‌نیاز: Node.js نسخه 22.22.1 یا جدیدتر و npm. فایل `.nvmrc` شاخه 22 را مشخص می‌کند. بسته‌ها با نسخه دقیق در `package-lock.json` ثبت شده‌اند.

```bash
npm ci
npm run dev
```

سپس [صفحه جست‌وجو](http://127.0.0.1:3000/hotels) را باز کنید. API key یا فایل env برای شروع لازم نیست؛ تنظیمات پیش‌فرض، Mock موفق با ۶۰۰ میلی‌ثانیه تأخیر است. برای تغییر تنظیمات می‌توانید `.env.example` را در `.env.local` کپی کنید و سرور را دوباره اجرا کنید.

برای تجربه سریع، روی «تهران» در مقصدهای پرطرفدار کلیک کنید. لینک پیشنهاد، اقامت دوشبه هفت روز بعد را از امروز تهران می‌سازد؛ بنابراین دمو به یک تاریخ ثابت گذشته وابسته نیست.

## ساخت و اجرای نسخه production

پیش از build، سرور توسعه را متوقف کنید تا خروجی‌های توسعه و production مخلوط نشوند.

```bash
npm run build
npm run start
```

اسکریپت‌ها از Webpack استفاده می‌کنند. در محیط بررسی، Turbopack هنگام پردازش CSS به bind محلی نیاز داشت که sandbox اجازه نمی‌داد؛ Webpack با موفقیت build شد. TypeScript همچنان در build بررسی می‌شود و API کامپایلر نصب‌شده جای CLI جداشده استفاده می‌شود. جزئیات در [تصمیم‌های فنی](docs/decisions.md) آمده است.

## رفتارهای قابل بررسی

- انتخاب مقصد، ورود و خروج شمسی، تعداد اتاق و مسافر با خطاهای فارسی و اعتبارسنجی دوباره در سرور.
- دو فیلتر قیمت هر شب و ستاره؛ دو ترتیب کمترین قیمت و بالاترین امتیاز.
- نگهداری جست‌وجو، فیلترها و sort در URL و بازیابی پس از Refresh یا Back/Forward.
- دریافت سروری داده با نمایش Skeleton، Empty و Error مستقل و تلاش مجدد.
- جزئیات و dialog بومی پیش‌نمایش، مبلغ کل برای تمام شب‌ها و اتاق‌ها، خروج با Escape و بازگشت فوکوس.
- تقویم فارسی با دکمه بومی، فعال‌سازی روز از صفحه‌کلید، Escape با بازگشت فوکوس و ورود متنی شمسیِ همگام؛ Enter آخرین متن را اعتبارسنجی می‌کند.

در Mock پنج شهر معتبر و ۱۲ هتل در چهار شهر وجود دارد؛ اصفهان به‌صورت طبیعی نتیجه ندارد. واحد canonical ریال و نمایش قیمت با برچسب تومان است. محدودیت‌های ظرفیت و تاریخ، تصمیم همین نسخه‌اند و در [قراردادها](docs/contracts.md) مشخص شده‌اند.

## بررسی‌های کد و مرورگر

```bash
npm run typecheck
npm run lint
npm test
npm run format:check
npm run build
npx playwright install chromium
npm run test:e2e
```

تست مرورگر روی production build و پورت 3100 سرور موقت خود را اجرا و متوقف می‌کند. برای سناریوهای دیگر، بدون تغییر فایل env:

```bash
E2E_SCENARIO=error E2E_PORT=3101 npm run test:e2e
E2E_SCENARIO=timeout E2E_PORT=3102 npm run test:e2e
E2E_SCENARIO=empty E2E_PORT=3103 npm run test:e2e
```

خروجی هر سناریو در پوشه جداگانه `test-results` و `playwright-report` می‌آید. تست‌های مربوط به سناریوهای دیگر عمداً skip می‌شوند. اگر Chromium سازگار از قبل نصب است، می‌توان مسیر آن را با `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` معرفی کرد. نتیجه واقعی اجراها، نسخه مرورگر و محدودیت‌ها در [گزارش بررسی](docs/verification.md) ثبت می‌شوند؛ جدول برنامه تست به‌تنهایی شاهد موفقیت نیست.

## همکاری با دستیار توسعه

[AGENTS.md](AGENTS.md) مرجع قواعد و [Skill هتل](skills/hotel-search/SKILL.md) راهنمای کار با این پروژه است. Skill همراه اسناد پروژه و با مسیر صریح در دستیارهای مختلف قابل استفاده است؛ نصب سراسری انجام نشده است.

```text
ابتدا AGENTS.md و skills/hotel-search/SKILL.md را بخوان.
تغییر درخواستی را با docs/contracts.md تطبیق بده.
شناسه نیازمندی مرتبط و فقط نتیجه بررسی‌های واقعاً اجراشده را گزارش کن.
```

پیش از ارسال برای مصاحبه، کد و محدودیت‌ها را شخصاً مرور کنید و Commitهای واقعی خود را ثبت کنید. مخزن Git محلی در همین مرحله ایجاد شده است؛ تاریخچه قدیمی بازسازی و Deploy انجام نشده است. هیچ امتیاز اندازه‌گیری‌نشده عملکرد یا ادعای انطباق کامل دسترس‌پذیری مطرح نمی‌شود.

# توسعه و بازبینی جریان جست‌وجوی هتل

این Skill همراه مستندات همین پروژه استفاده می‌شود و خودش مجوز شروع پیاده‌سازی، انتشار یا تغییر محدوده نیست. ابتدا [قواعد مشترک](../../AGENTS.md) و [وضعیت پروژه](../../README.md) را بخوانید؛ فایل‌های مرجع نسبت به محل این Skill قابل دسترسی‌اند.

## انتخاب منابع متناسب با درخواست

| درخواست | منابع لازم |
| --- | --- |
| شروع یا ادامه پیاده‌سازی | [نیازمندی‌ها](../../docs/requirements.md)، [معماری](../../docs/architecture.md) و مرحله مرتبط [تحویل](../../docs/delivery.md) |
| فرم، تاریخ، URL یا سرویس | بخش مرتبط [قراردادها](../../docs/contracts.md) |
| تغییر معماری یا وابستگی | [تصمیم‌ها](../../docs/decisions.md) و معماری فعلی کد |
| بازبینی | نیازمندی‌های مرتبط، قرارداد رفتار تغییرکرده و سناریوهای تحویل |
| آماده‌سازی توضیح برای ارزیاب | [راهنمای مصاحبه](../../docs/interview-guide.md) و شواهد واقعی کد |

همه منابع را برای هر ویرایش کوچک بارگیری نکنید. نیازمندی مربوط را با شناسه مشخص کنید و طرح را در برابر کد موجود بسنجید.

## هنگام پیاده‌سازی

یک بخش انتها‌به‌انتها از برنامه تحویل را انتخاب کنید. برای بخش انتخاب‌شده، رفتار موفقیت و خطای مربوط را با هم کامل کنید. پیش از افزودن UI، ورودی و خروجی آن را از قرارداد موجود استخراج کنید؛ برای حالت بدون تصمیم، فرض مؤثر را روشن و در مرجع مناسب ثبت کنید.

فقط فایل‌هایی را بسازید که همان بخش نیاز دارد. در پایان، بررسی‌های مربوط را اجرا کنید و مستندات وضعیت را با نتیجه واقعی هماهنگ کنید. از تکثیر قواعد AGENTS یا قراردادها در این Skill خودداری کنید.

## هنگام بازبینی

تغییر را از ورودی کاربر یا URL تا سرویس و خروجی قابل مشاهده دنبال کنید. بررسی کنید آیا می‌توان خطا را با سناریوی مشخص بازتولید کرد. یافته‌ها را با اثر بر کاربر، محل دقیق و روش بازتولید گزارش کنید؛ پیشنهاد سلیقه‌ای را نقص عملکرد معرفی نکنید. اگر درخواست فقط بازبینی است، بدون درخواست اصلاح، کد را تغییر ندهید.

## معیار پایان کار

رفتار مورد درخواست و معیارهای پذیرش مرتبط باید شاهد داشته باشند. گزارش نهایی باید شناسه نیازمندی، بررسی اجراشده، نتیجه و محدودیت را روشن کند. وجود فایل یا موفقیت build به‌تنهایی اثبات صحت تاریخ، بازیابی URL یا دسترس‌پذیری نیست. راهنمای مصاحبه باید فقط تصمیم‌ها و رفتارهای واقعاً قابل نمایش را بیان کند.

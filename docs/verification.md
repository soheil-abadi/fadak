# گزارش بررسی نسخه محلی

تاریخ بررسی: ۲۰۲۶/۱۱/۰۷ به وقت تهران. این گزارش فقط اجراهای ثبت‌شده و مرور کد همین نسخه را توصیف می‌کند؛ همه سناریوهای برنامه تحویل یا همه مرورگرها تأیید نشده‌اند.

## محیط و شناسه نسخه

| مورد | مقدار |
| --- | --- |
| سیستم | Linux x64 |
| Node و npm | Node 22.22.1 و npm 9.2.0 |
| Framework | Next.js 16.4.5، React 19.3.1؛ Webpack |
| تست | Vitest 5.1.0 و Playwright 1.65.0 |
| مرورگر بررسی | Chrome for Testing 151.0.7922.34؛ Chromium موجود با مسیر صریح |
| تنظیم Mock در E2E | تأخیر ۱۰۰۰ میلی‌ثانیه؛ سناریوهای success، error، timeout و empty در سرورهای جدا |
| شناسه snapshot منبع | `6d241de216805e9fdd84fbbb06773d045407ef8441e479094bddfc697f52730e` |

شناسه بالا SHA-256 محتوای مسیرهای src، tests و public و تنظیمات build/test و lockfile است؛ فایل‌های گزارش و خروجی build در آن نیستند. این شناسه جای Commit Git نیست. مخزن محلی در همین مرحله ایجاد شده است؛ تاریخچه قدیمی بازسازی نشده و Push یا Deploy انجام نشده است.

## بررسی‌های اجراشده

| بررسی | نتیجه و حدود آن |
| --- | --- |
| `npm ci` | نصب از lockfile موفق؛ فایل env یا API key لازم نبود. |
| `npm run typecheck` | موفق با strict و noUncheckedIndexedAccess. |
| `npm run lint` | موفق بدون warning یا error کد پروژه. |
| `npm run format:check` | موفق؛ فایل تولیدشده next-env.d.ts از formatter مستثناست. |
| `npm test` | ۵۷ تست در شش فایل موفق؛ منطق تاریخ، schema، URL، دامنه، provider و فرم. |
| تقویم در سه timezone | هر ۱۱ تست تقویم در UTC، Asia/Tehran و America/Los_Angeles موفق. این ۳۳ اجرا، تست‌های جدید مستقل به شمارش ۵۷ اضافه نمی‌کنند. |
| `npm run build` | موفق؛ `/hotels` و جزئیات dynamic و ریشه و icon به شکل static تولید شدند؛ TypeScript در build هم بررسی شد. |
| مرورگر success | شش سناریوی فعال موفق؛ دو سناریوی مختص حالت دیگر عمداً skip شدند. |
| مرورگر error | سناریوی خطای سرویس و retry روی همان URL موفق؛ هفت سناریوی نامرتبط skip شدند. |
| مرورگر timeout | سناریوی timeout شبیه‌سازی‌شده و retry روی همان URL موفق؛ هفت سناریوی نامرتبط skip شدند. |
| مرورگر empty | پاسخ خالی موفق بدون Error یا دکمه retry تأیید شد؛ هفت سناریوی نامرتبط skip شدند. |
| مرز داده سرور | نام تنظیمات HOTEL_MOCK و قیمت خام fixture در فایل‌های JS کلاینت تولیدشده پیدا نشد؛ محافظ server-only نیز در مرز composition و زیرساخت وجود دارد. این بررسی جای ممیزی امنیت جامع نیست. |
| `npm audit --omit=dev` | صفر advisory در وابستگی‌های runtime در زمان این بررسی. |

ماتریس اصلی چهار پیکربندی شامل ۹ بررسی فعال موفق است؛ تست responsive پس از اصلاح چیدمان و اطمینان از بارگذاری تصاویر نیز جداگانه تکرار شده است. سناریوی failure در هر دو تنظیم error و timeout اجرا شده و دو آزمون مستقلِ متفاوت محسوب نمی‌شود. فایل [تست مرورگر](../tests/e2e/hotel-search.spec.ts) جزئیات قابل تکرار را دارد.

## شواهد رفتاری و نگاشت نیازمندی‌ها

| نیازمندی | شاهد |
| --- | --- |
| R-01، R-07، R-16 | جریان مرورگر از جست‌وجو تا جزئیات و dialog؛ مبلغ ۳٬۹۰۰٬۰۰۰ تومان برای fixture چهارستاره و دو شب بررسی شد. |
| R-02 تا R-06، R-25 تا R-27، R-29 | مرور ساختار import و composition، Type از schema، build و تزریق provider در تست سرویس؛ provider خارجی واقعی پیاده نشده است. |
| R-08، R-09، R-23 | ۱۲ fixture جدا، Type و schema پاسخ، تست رد داده نامعتبر، ظرفیت، تعداد اتاق و عدم تغییر fixture. |
| R-10 | Skeleton در مرور واقعی صفحه و AX هنگام پاسخ async مشاهده شد. این مورد تست خودکار زمان‌بندی اختصاصی ندارد. |
| R-11 و R-12 | شهر اصفهان بدون fixture، حالت forced-empty و دو حالت خطای سرور با retry؛ خطا به فهرست خالی تبدیل نشد. |
| R-13 تا R-15 | تست مرز فیلتر قیمت، دو sort، tie-break، query نامعتبر، round-trip، Refresh و Back/Forward و اعمال پشت‌سرهم sort و فیلتر. فیلتر دو ستاره با نتیجه خالی نیز در UI بازیابی شد. |
| R-17 | نبود overflow افقی در عرض‌های ۳۷۵، ۷۶۸ و ۱۴۴۰ پیکسل و تصاویر زیر؛ تست عرض، جای دستگاه فیزیکی را نمی‌گیرد. |
| R-18 تا R-21 | تبدیل‌های نوروز و کبیسه، عدم mutate انتخاب، مرز افق و مدت اقامت، timezone و ورود متن فارسی؛ انتخاب range با Enter نیز در مرورگر انجام شد. |
| R-24 و R-30 | تنظیمات فقط سروری، absence کلیدهای تنظیم در bundle، جست‌وجوی dynamic و بررسی Refresh؛ Mock مستقیم fetch ندارد و سیاست آداپتور خارجی، طراحی no-store است. |
| R-31 تا R-33 | loading، error و not-found در کد؛ شناسه ناموجود در مرورگر، نبود pageerror در جریان اصلی، تصاویر محلی با next/image و sizes و فونت محلی. خطای غیرمنتظره مسیر عمداً تزریق نشده است. |
| R-34 تا R-36 و R-38 | README با دستورهای اجراشده، قرارداد و تصمیم‌های به‌روز، متن‌های محصول و نام‌های تقویم فارسی؛ دارایی‌های تصویری نمایشی مشخص شده‌اند. |
| R-22 و R-28 | انتخاب روز با صفحه‌کلید و ورود متن، Escape و بازگشت فوکوس dialog بررسی شد. آزمون صفحه‌خوان، تمام رفتارهای grid، تست لمس روی دستگاه واقعی و ممیزی کامل کنتراست باقی است؛ وضعیت این دو ردیف نیازمند بررسی مانده است. |
| R-37 و R-39 | مخزن محلی ایجاد شده؛ تاریخچه فعلی واقعی است. مرور و فهم کد توسط داوطلب همچنان باید شخصاً انجام شود؛ این گزارش آن را تأیید نمی‌کند. |

State انتظار navigation میان فرم، فیلتر و sort از یک Context سبک UI به اشتراک گذاشته می‌شود؛ هیچ query یا نتیجه سروری در آن کپی نمی‌شود. این قفل تا commit شدن navigation است و الزاماً تا پایان stream نتایج ادامه ندارد. تست به حفظ مقادیر URL بعد از دو اقدام نزدیک به هم تکیه دارد و حداقل مدت نمایش حالت disabled را فرض نمی‌کند.

## محدودیت و کار باقی‌مانده

- رزرو و پرداخت واقعی، API زنده، موجودی روزانه، مالیات پویا و مدل سن مسافر ساخته نشده‌اند؛ محدودیت عمدی نسخه‌اند.
- آزمون جامع صفحه‌خوان، رفتار پیشرفته grid، همه حالت‌های zoom و لمس واقعی اجرا نشده است. اعداد Lighthouse یا تضمین WCAG ارائه نمی‌شود.
- هنگام نصب، هشت advisory متوسط در ابزارهای توسعه گزارش شد؛ مسیر اصلی از minimatch و زنجیره TypeScript ESLint بود. شاخه سازگار ESLint 9 نیز هشدار پایان پشتیبانی دارد. runtime audit جداگانه صفر بود. برای رفع این مورد باید نسخه‌های سازگار lint با upstream دوباره بررسی شوند؛ force downgrade روی Next انجام نشده است.
- API compiler در Next از طریق تنظیم experimental فعال شده است؛ هنگام ارتقای TypeScript یا Next این انتخاب دوباره بررسی شود. build و typecheck فعلی هر دو موفق‌اند.
- Git remote و Deploy ایجاد نشده‌اند. Commit جاری یک snapshot واقعی از کار انجام‌شده است و سابقه مرحله‌بندی‌شده ساختگی ایجاد نمی‌شود.
- داوطلب باید قبل از ارسال، کد و محدودیت‌ها را مرور کند و بتواند تصمیم‌ها را با بیان خود توضیح دهد.

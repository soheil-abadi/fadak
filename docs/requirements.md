# نیازمندی‌ها و معیارهای پذیرش

منبع استخراج، سند «تسک ارزیابی توسعه دهنده فرانت اند.docx» است. شماره‌های ارجاع زیر، شماره بخش‌های همان سند هستند؛ شماره صفحه از استخراج متن قابل اثبات نبود و استفاده نشده است. مسیر هتل با انتخاب داوطلب تثبیت شده است. متن این فایل بازنویسی معیارهای قابل بررسی است و جای درخواست مستقیم کاربر را نمی‌گیرد.

## راهنمای طبقه‌بندی و وضعیت

- **الزام:** در صورت مسئله یا معیارهای کیفیت خواسته شده است.
- **مجاز یا پیشنهادی سند:** روشی قابل قبول یا پیشنهاد کارفرماست؛ الزام انحصاری نیست.
- **تصمیم پروژه:** برای اجرای مشخص همین نسخه انتخاب شده است.
- **اختیاری:** پس از تکمیل جریان اصلی بررسی می‌شود.

وضعیت‌ها به نسخه اجرایی بررسی‌شده مربوط‌اند. شاهد بررسی کد، build و سناریوهای مرورگر در [گزارش بررسی](verification.md) با شناسه نیازمندی آمده است. «تأیید شده» به معنای پوشش همان معیار در حدود بررسی ثبت‌شده است؛ انطباق کامل دسترس‌پذیری یا آمادگی Production از آن نتیجه نمی‌شود. موارد وابسته به مرور انسانی داوطلب یا تاریخچه Git همچنان باز هستند.
